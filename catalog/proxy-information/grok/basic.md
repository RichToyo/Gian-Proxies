# Grok Build: basic information review

Basic information shows the Runtime path, the Runtime version, and the Proxy version. The candidate release target is Proxy **0.4.0** and Grok CLI **1.0.92**. That does not mean the user's machine has finished install or sign-in.

Target location:

```text
<dataDir>/runtimes/grok/1.0.92/<artifact-sha256>/bin/grok
```

Agent HOME, account state, and native sessions are not part of the signed Catalog, and they are not inherited automatically from another `~/.grok`.
