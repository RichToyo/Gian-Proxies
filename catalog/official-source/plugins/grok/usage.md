# Usage

Create sessions with a model from the Runtime's live list (for example Grok 4.6 or Grok 4.5, plus any custom model in the Agent's `config.toml`), choose a reasoning effort when the model offers one, and approve requested tools through Gian. Model and effort changes use the CLI's standard session config options. Steer, Rename, Fork and Side Chat use Grok's native methods once the Runtime confirms them. The surface includes text, local files, images, tool interaction, usage and replay.
