# Setup

Install Grok Build from Agent Integrations. Gian downloads and verifies the exact Proxy and Runtime combination (Grok CLI 1.0.92) before activation. Create an Agent, then sign in with `grok login` in that Agent's maintenance terminal so the credential stays in the Agent's isolated HOME. A model with its own API key in that HOME's `config.toml` also lets sessions start without signing in.
