# DeepSeek Harness

DeepSeek Harness is a product-visible Gian executor. Its plugin identity is the reverse-domain id `ai.deepseek.harness`.

DeepSeek Harness Proxy 0.4.1 pairs its bundled Bridge 0.1.12 with the managed DeepSeek Harness Runtime 0.2.2-rc.5; it becomes a published combination once it is qualified and signed. Gian starts every DSH with telemetry disabled and without the DeepSeek Session-log upload.
